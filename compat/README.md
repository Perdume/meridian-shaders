# Meridian (screen-space shadows)

Meridian for Horizon 0.2.97 and Nightlies before 2026-11-01, which have no shadow map: sun shadows traced through the
depth buffer, shade under trees and roofs from sky light, and water whose clarity is its opacity. Built from Meridian's
sources with this folder's files in place of theirs (`tools/build_packs.py`). MIT licensed.
